EVM NFT Bulk Transfer

A local, wallet-connected utility for finding ERC-721 / ERC-1155 holdings in a collection and moving selected assets to another wallet. No private keys are requested or stored.
v2 · client-side only

        Manual token IDs / fallback
        
Useful if the RPC blocks large event scans or the collection is non-standard. ERC-721 IDs will be verified against ownerOf. ERC-1155 IDs will be checked with balanceOf.
